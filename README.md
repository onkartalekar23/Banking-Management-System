# Banking Management System

## Project Description
Banking Management System is a SQL-based database management project developed using MySQL.

The main objective of this project is to store, manage, and retrieve banking information in a structured way.

## Modules
1. Branch Management
2. Customer Management
3. Account Management
4. Transaction Management
5. Loan Management

## Technologies Used
- MySQL
- SQL

## SQL Concepts Used
- DDL, DML, DQL
- Primary Key and Foreign Key
- Constraints
- Joins
- Subqueries
- Aggregate Functions
- Window Functions
- Views
- Stored Procedures

## Project Features
- Store customer details.
- Manage bank account information.
- Maintain branch records.
- Store transaction details.
- Manage customer loan information.
- Retrieve data using SQL queries.

## Project Objective
To organize banking information and perform database operations efficiently.

## Note
This is a database management project for learning SQL concepts. It is not a live banking application.
